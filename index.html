Variablen speichern Werte. In JavaScript entstehen sie mit let – einmal, beim ersten Mal (var geht auch). Danach kannst du den Wert beliebig ändern.

02_variablen.js
// 02_variablen.js

// Variablen erstellen mit let (beim 1. Mal)
let x = 5
// kann man auch mit var
var y = 6

console.log(x)
// Variable kann einen neuen Wert bekommen
x = 10
console.log(x)

// Variablenwert erhöhen (etwas dazuzählen)
x = x + 8

// Variablentypen
let zahl = 7 // ganze Zahl - integer
let komma = 4.5 // Kommazahl - float
let zeichen = "Hallo" // Text - string
let wahrheitswert = true // boolean (true/false)

// Variablenwert um GENAU 1 erhöhen
zahl++

// Ausgabe Variablen & Text mit PLUS
console.log("Die Variable zahl hat den Wert "+zahl)
console.log("In der Variable zeichen steht "+zeichen+" drin")
💻 Terminal – 02_variablen.js
5
10
Die Variable zahl hat den Wert 8
In der Variable zeichen steht Hallo drin

🔍 Was du hier lernst

  • let x = 5 erstellt die Variable – später reicht x = 10 (ohne let!)
  • x = x + 8 erhöht den Wert – zahl++ addiert genau 1 (Kurzform von zahl = zahl + 1)
  • Die Datentypen: integer (ganze Zahl), float (Kommazahl), string (Text), boolean (true/false)
  • Text und Variablen hängst du mit + zusammen: "Wert: "+zahl
Achtung: Schreibst du let x = ... zweimal, gibt es einen Fehler („x has already been declared“). let nur beim ersten Mal!
✏️ Deine Aufgabe: Lege Variablen für Name, Alter und Lieblingszahl an. Erhöhe das Alter um 10 und gib einen schönen Satz aus.

🔍 Was du hier lernst

Dein Programm soll entscheiden: Kommt die Person in den Club oder nicht? Unser Beispiel ist ein Türsteher-Check – dafür gibt es die Abfrage mit if, else if und else.

04_abfrage.js
// 04_abfrage.js

const prompt = require("prompt-sync")()

let alter = Number(prompt("Wie alt bist du: "))

// Wir programmieren einen Türsteher-Check

// Überprüfung / Verzweigung / Abfrage mit if
if (alter < 18) {
    console.log("Heute leider nicht...")
}
else if (alter <= 21) {
    console.log("Komm rein, aber keine harten Drinks")
}
else if (alter == 25) { // wenn man gleich prüfen will, dann ==
    console.log("Happy 25!")
}
else {
    console.log("Viel Spaß!!")
}

🔍 Was du hier lernst

  • JavaScript prüft von oben nach unten – die erste wahre Bedingung gewinnt, der Rest wird übersprungen
  • < und <= vergleichen Zahlen, == prüft auf Gleichheit
  • else greift, wenn keine Bedingung stimmt
Merke dir: Die Reihenfolge ist entscheidend! Prüfe immer von eng nach weit. Mit alter = 25 gibt unser Programm „Happy 25!“ aus – die Bedingung alter == 25 gewinnt vor dem else.
Achtung: Vergiss Number() bei der Eingabe nicht! Sonst arbeitest du mit dem String "25" statt der Zahl 25.
✏️ Deine Aufgabe: Schreibe eine Noten-Abfrage: 1 → „Sehr gut“, 2 → „Gut“, 3–4 → „Bestanden“, 5–6 → „Nicht bestanden“.

Manchmal müssen mehrere Dinge gleichzeitig stimmen – Username und Passwort. Dafür verkettest du Bedingungen mit logischen Operatoren.

04a_abfrage.js
// 04a_abfrage.js
const prompt = require("prompt-sync")()

// Passwort-Überprüfung
// richtiges Passwort: admin
// richtiger Username: administrator

let username = prompt("Gib Username ein: ")
let eingabe = prompt("Gib Passwort ein: ")

// wenn man 2 Sachen zugleich überprüfen möchte: && (UND)
if (eingabe == "admin" && username == "administrator") {
    console.log("Richtige Zugangsdaten!")
}
else {
    console.log("Zugangsdaten falsch!")
}

// wenn eine von zwei Überprüfungen zutreffen können: || (ODER)
// != bedeutet NICHT GLEICH
if (eingabe != "admin" || username != "administrator") {
    console.log("Passwort oder Username falsch.")
}

🔍 Was du hier lernst

  • && (UND): beide Bedingungen müssen wahr sein
  • || (ODER): mindestens eine Bedingung muss wahr sein
  • != heißt „nicht gleich“ – das Gegenteil von ==
Merke dir: && verlangt, dass beide Bedingungen wahr sind, bei || reicht eine. Beispiel aus 04a_abfrage.js: eingabe == "admin" && username == "administrator" → „Richtige Zugangsdaten!“
✏️ Deine Aufgabe: Baue eine Alters-UND-Wohnort-Abfrage: „Zutritt nur, wenn du mindestens 18 bist und aus Wien kommst“.

🔍 Was du hier lernst

  • zahl.toFixed(2) → genau 2 Nachkommastellen: 15.47

Mit Math.random() erzeugt JavaScript Zufallszahlen – die Basis für Spiele wie das Zahlenraten. Die Formel sieht tricky aus, ist aber ein festes Muster.

06_zufallszahlen.js
// 06_zufallszahlen.js

// Zufallszahlen in JS mit Math.random()
// mit oberer Grenze multiplizieren 

let zuza = Math.floor(Math.random()*10)+1
console.log(zuza)

let zuza2 = Math.floor(Math.random()*200)+1
console.log(zuza2)

🔍 Die Formel Schritt für Schritt

  • Math.random() liefert eine Kommazahl zwischen 0 und 1 (z. B. 0.7284…)
  • * 10 macht daraus 0 bis 9.99… – * 200 entsprechend 0 bis 199.99…
  • Math.floor() schneidet die Kommastellen ab → 0 bis 9 bzw. 0 bis 199
  • + 1 schiebt alles hoch → 1 bis 10 bzw. 1 bis 200 ✓
Merke dir: Das Muster ist immer gleich: Math.floor(Math.random()*OBERE_GRENZE)+1 liefert eine ganze Zahl von 1 bis OBERE_GRENZE. Einen Würfel baust du mit *6.
✏️ Deine Aufgabe: Simuliere einen Würfel: gib bei jedem Start eine zufällige Zahl von 1 bis 6 aus.

Etwas 10-mal wiederholen? Dafür gibt es die for-Schleife – definiert über drei Parameter.

07_for-schleife.js
// 07_for-schleife.js

// FOR Schleife (definiert mit 3 Parametern)
// 1. Parameter: Startwert (wo zählt die Schleife los?)
// 2. Parameter: Endwert/Abbruchbedingung (wie weit zählt die Schleife?)
// 3. Parameter: Schrittweite (in welchen Schritten zählt die Schleife?)

for (i=1; i<=10; i++) {
    console.log("FOR Schleife "+i)
}
💻 Terminal – 07_for-schleife.js
FOR Schleife 1
FOR Schleife 2
...
FOR Schleife 10

🔍 Was du hier lernst

  • Startwert: i=1 – die Zählvariable beginnt bei 1
  • Abbruchbedingung: i<=10 – läuft, solange i kleiner oder gleich 10 ist
  • Schrittweite: i++ – erhöht i nach jedem Durchlauf um 1
Merke dir: Einzige Besonderheit: In unserer Datei wird die Variable i ohne let deklariert. Sauberer wäre let i=1 – beide Varianten funktionieren in unseren Programmen.
✏️ Deine Aufgabe: Zähle von 1 bis 20 – und dann rückwärts von 10 bis 1 (Tipp: Schrittweite i-- statt i++).

Die while-Schleife hat nur einen Parameter: die Abbruchbedingung. Sie läuft, solange etwas wahr ist – ideal, wenn du die Anzahl noch nicht kennst.

08_while-schleife.js
// 08_while-schleife.js

// WHILE Schleife (nur 1 Parameter)
// Parameter: Abbruchbedingung

let i = 1

while (i<=10) {
    console.log("WHILE Schleife "+i)
    i++
}
💻 Terminal – 08_while-schleife.js
WHILE Schleife 1
WHILE Schleife 2
...
WHILE Schleife 10

🔍 for oder while – wann was?

  • for: wenn du weißt, wie oft die Schleife laufen soll („zähle von 1 bis 10“)
  • while: wenn du nur eine Bedingung kennst („solange der Tipp falsch ist“)
Achtung: Bei while steht i++ im Schleifenkörper – vergisst du es, bleibt die Bedingung für immer wahr: Endlosschleife! Abbrechen kannst du im Terminal mit Strg + C.
✏️ Deine Aufgabe: Gib mit einer while-Schleife die Zahlen 20, 18, 16, … bis 2 aus (Tipp: Schrittweite i = i-2).

Das wichtigste Muster für interaktive Programme: Die Schleife läuft immer wieder – bis der Benutzer sagt, dass Schluss ist.

09_while-mit-frage.js
// 09_while-mit-frage.js
const prompt = require("prompt-sync")()

let nochmal = "ja"

while (nochmal == "ja") {
    console.log("Hallo, ich bin ein Pseudo Programm")

    nochmal = prompt("Willst du noch mal starten? (ja/nein): ")
}
💻 Terminal – 09_while-mit-frage.js
Hallo, ich bin ein Pseudo Programm
Willst du noch mal starten? (ja/nein): ja
Hallo, ich bin ein Pseudo Programm
Willst du noch mal starten? (ja/nein): nein

🔍 Was du hier lernst

  • Die Variable nochmal startet mit "ja" – so läuft die Schleife mindestens einmal
  • Am Ende des Schleifenkörpers wird neu gefragt – antwortet der Benutzer „nein“, endet die Schleife
  • Dieses Muster steckt in kopfrechnen_2b.js und zahlenraten.js!
Merke dir: Das ist der Bauplan für fast jedes Spiel und jedes interaktive Programm: Schleife → Programmteil → Frage am Ende.
✏️ Deine Aufgabe: Bau einen Mini-Chatbot: Er stellt eine Frage, antwortet mit einem Witz – und fragt dann, ob er noch einen erzählen soll.
